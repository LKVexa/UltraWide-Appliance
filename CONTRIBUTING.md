# Testing and contributions

This is a product preview governed by [LICENSE](LICENSE). Evaluation and
testing are welcome. Production or commercial distribution needs separate
written permission from the owner.

Run the README checks before proposing changes. Include your Python version,
the exact command, expected behavior, actual behavior, and a minimal example
with a bug report. Describe the input word width and the program's source
hash when relevant. Never include secrets, private corpora, personal files,
model weights, or complete VM state in an issue or pull request.

Keep the generic runtime separate from optional application integrations.
Tests should demonstrate arithmetic behavior or boundary/error handling,
not depend on a particular workstation. New instructions need documented
semantics, input bounds, and tests. Intentionally submitted code contributions
are covered by the contribution provision in LICENSE; no copyright transfer
is required.
